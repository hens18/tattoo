# His Work — gallery videos

Drop Inky Dollaz's tattoo videos here as `work-01.mp4`, `work-02.mp4`, … (vertical 9:16 clips from Instagram Reels work best).
Optional poster frames go alongside as `work-01.jpg`, etc.

To add, remove, or rename pieces, edit the `WORK` list at the top of `script.js`.
Tiles whose video file is missing show a "Video coming soon" placeholder.

For the hero background, add a shop/artist photo at `assets/hero.jpg`.
